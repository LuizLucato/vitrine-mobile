# Vitrine

A Vitrine é um app Expo (SDK 54) do curso de Dispositivos Móveis 2026, feito para apresentar o aluno e o projeto em um celular.

Para rodar: instale as dependências com `npm install` e inicie o com `npx expo start`.

No terminal, escolha Android, iOS ou web, ou leia o QR code com o Expo Go no celular.
